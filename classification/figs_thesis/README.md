## Figure B.11

![Figure B.11](B.11_power-family.png)

Figure B.11. The power-normalized OU family, S = K tau^beta/(1 + tau^2 omega^2) (Theorems 7.8, 7.9). lambda = 1, Sigma = 0.01,
K = 1. Colour: optimal error relative to its supremum over tau, P/sup P (one hue, light to dark). For beta <= 0 the sweep
is a causal information ordering (information increasing in tau) and P is non-increasing; for beta >= 2 it is ordered the
other way and P is non-decreasing; for 0 < beta < 2 every pair of spectra crosses, P -> 0 at both ends, and P has exactly
one turning point (orange), so the optimal failure set is a single window. beta = 0 is matched zero-frequency power,
beta = 1 matched variance.

## Figure B.12

![Figure B.12](B.12_delay.png)

Figure B.12. Causality is essential (Proposition 7.11, Counterexample 7.12). lambda = 1, Sigma = 0.01, Pi = 1. Observations
delayed by d(theta) = theta exp(-theta): every member is a time shift of the same path, so all are pathwise
Blackwell-equivalent, yet the optimal filtering error P(d) = F - exp(-2 lambda d)(F - sigma*^2) rises then falls, from
sigma*^2 = 0.0099505 to P(1/e) = 0.0099763 at theta = 1. For sigma*^2 < R^2 < P(1/e) the optimal failure set is a window
(shaded at R^2 = 0.0099634).

## Figure B.8

![Figure B.8](B.8_optimal-sampling.png)

Figure B.8. The optimal filter along the sampling interval (Theorem 6.19, Proposition 7.16). Point-sampled model M-P,
lambda = 1, Sigma = 0.01, Pi = 1 (per-sample noise variance 1/(Pi dt)). The error at sample times (post) falls strictly from
sigma*^2 to 0, while the error just before samples (prior) and the time average rise strictly from sigma*^2 to F. Because
the metrics move in opposite directions, the dt sweep is not a causal information ordering in either direction.

## Figure B.10

![Figure B.10](B.10_process-noise.png)

Figure B.10. The process-noise sweep on a moving floor F = Sigma/lambda (Lemma 6.23, Propositions 6.24-6.27). lambda = Pi = 1.
Left, absolute tolerance (fixed R^2): the Sigma-independent gain (G = 1), the Sigma-tracking gain over-trusting precision by
rho = 10, and the optimal filter are all increasing, so only All or an upper ray occur. Right, relative tolerance
(failure when sigma^2 > rF): the Sigma-independent gain decreases to 1/(1 + g), the optimal filter decreases as

exactly when rho > 2, the starting study's factor of two.

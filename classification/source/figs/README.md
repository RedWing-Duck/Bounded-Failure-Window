## {{fig:power-family}}

{{fig:power-family}}. The power-normalized OU family, S = K tau^beta/(1 + tau^2 omega^2) (Theorems [[power-family-sharpness|n]], [[power-family-unimodal|n]]). lambda = 1, Sigma = 0.01,

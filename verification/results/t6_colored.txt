    def make_sensory(tau, seed):
        """Unit OU noise (integrated autocovariance 1), returned as eta*dt increments."""
        rho = np.exp(-DT / tau)
        var = 1.0 / (2 * tau)
        innov = np.sqrt(var * (1 - rho**2))
        state = {"z": np.random.default_rng(seed).standard_normal((NTRAJ, 1)) * np.sqrt(var) * rho}
    
        def sensory(k, dWs):
            xi = dWs / np.sqrt(DT)                 # reuse the common white draws as OU innovations
            eta, state["z"] = lfilter([innov], [1.0, -rho], xi, axis=1, zi=state["z"])
            return eta * DT
        return sensory

t4b generates a unit OU process eta_u by exact AR(1) discretisation, rho = exp(-dt/tau), innovation sd = sqrt((1/(2tau))(1-rho^2)), started from its stationary law, so eta_u has stationary variance 1/(2tau) and integrated autocovariance 2*tau*(1/(2tau)) = 1, i.e. d eta_u = -eta_u/tau dt + (1/tau) dW_s. The relay multiplies eta_u*dt by gs = G/sqrt(Pi), so the effective sensory noise is eta = eta_u/sqrt(Pi): stationary variance 1/(2 Pi tau), integrated autocovariance 1/Pi, d eta = -eta/tau dt + (1/(tau sqrt(Pi))) dW_s. This MATCHES the expected normalisation.
(The discrete sum of the AR(1) autocovariance times dt differs from 1 by O((dt/tau)^2) from discretisation; the continuous-time integral 2*var*tau is exactly 1.)
